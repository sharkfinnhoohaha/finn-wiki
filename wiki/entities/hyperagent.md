# HyperAgent

Agent-builder product by Howie Liu at [[airtable]]. Lets you build fleets of agents that operate on Airtable data with record-change triggers. Finn has $1k credits + 2.5x Opus 4.6 subsidy.

Used as the hosted runtime for the [[openclaw-fleet]] fleet. See [[isenberg-howieliu-hyperagent-2026-04-29]] for the source.
